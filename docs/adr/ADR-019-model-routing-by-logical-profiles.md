# ADR-019 — Model routing uses logical profiles

- **Status:** Accepted
- **Scope:** backend
- **Origin:** master blueprint §82
- **Supersedes:** —
- **Superseded by:** —

## Decision

Model routing uses logical profiles and declared capabilities rather than hard-coded model names.

## Rationale / consequence

FAST/REASONING/JUDGE/VISION/EMBEDDING/LOCAL_PRIVATE can resolve differently by environment/security policy without changing business logic.
