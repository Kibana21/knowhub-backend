# ADR-015 — Internal domain events modeled, event bus deferred

- **Status:** Accepted
- **Scope:** backend
- **Origin:** master blueprint §82
- **Supersedes:** —
- **Superseded by:** —

## Decision

Internal domain events are modeled now; Service Bus/Kafka deferred.

## Rationale / consequence

Preserves future decoupling without adding unnecessary V1 infrastructure.
