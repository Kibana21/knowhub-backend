# ADR-005 — Graph stored canonically in Postgres

- **Status:** Accepted
- **Scope:** backend
- **Origin:** master blueprint §82
- **Supersedes:** —
- **Superseded by:** —

## Decision

Graph stored canonically in Postgres; Neo4j only as derived projection later.

## Rationale / consequence

Graph engine remains replaceable/rebuildable.
